# IDEIAS PARA AVALIAÇÃO
- **Template mais elaborado para o orçamento em pdf:**
  - Adição de borda no template do orçamento;
  - Adição de logomarca do prestador de serviço
  - Adição do contato do pretador de serviço
- **Ícones nos títulos:** Associar os títulos a imagens para tornar o uso do software mais intuitivo.
  - Adicionar ícones equivalentes às palavras no lado esquerdo. Exemplo: ícone de um rolinho no lado esquerdo da palavra 'Filamento'.
- **Imagens de impressoras:** Tal qual é feito no orca slicer, adicionar imagens dos modelos das impressoras quando for selecioná-las e essa imagem deve aparecer na lista de impressoras adicionadas. Isso se justifica pela facilidade de uso, pois o usuário processará a imagem mais rápido que apenas o texto. Checar que fere algum direiro autoral o uso das fotos da impressoras.
- **Tempo de impressão:** Informar tempo de impressão no orçamento (automático e manual). Isso vai informar ao cliente o tempo de fabricação da peça selecionada. É interessante apresentar o custo da impressão com uma impressão rápida, mas de qualidade menor, e uma impressão demorada, mas com maior qualidade no acabamento. Dessa forma, oferecer mais de uma opção ao cliente vai facilitar a sua escolha. Além disso, para os leigos, saber que a qualidade da peça pode ser reduzida para ganhar tempo de fabricação é uma novidade e merece ser informada.
- **Prazo de entrega:** A previsão (prazo) de entrega é interessante para que o cliente saiba quando o seu produto será entregue, caso autorize a fabricação. Destacar essa informação no orçamento é útil.
- **Nova aba: Manutenção:** Apresentar as métricas de manutenção ajudará no planejamento da produção e garantia de retorno do investimento com a impressora.
  - Alerta de troca de bico
  - Alerta de lubrificação
  - OBS: convém ressaltar que para os alertas serem efetivos, o usuário deve registrar que os serviços de impressão foram executados. Logo, cabe uma opção (ou botão) para informar ao sofware que o orçamento feito foi aprovado, inclusive, deve/pode haver a opção de incluir tempos de impressão que não foram orçadas, assim é possível contabilizar tempo de produção da impressora.
