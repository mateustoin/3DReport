# Decisão 34: Versão do app vira 1.0.0 porque o jpackage do macOS exige major maior ou igual a 1

- **Data:** 2026-09-15
- **Status:** Aprovada

Ao tentar cortar o primeiro release (`v0.3.0`), o bundler do macOS rejeitou o build: jpackage exige que o primeiro número do `app-version` seja **≥ 1** (regra do próprio Apple/jpackage, não contorná­vel com `0.x`). Em vez de uma gambiarra só pro macOS (versão de exibição diferente da versão real do pacote), a versão do app **vira `1.0.0`** — condizente com ser o primeiro release de fato publicado. `0.1.0`/`0.2.0` continuam no `CHANGELOG.md` como histórico do desenvolvimento antes do primeiro release; nenhuma versão `0.x` chegou a ser publicada como release
