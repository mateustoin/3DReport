# Decisão 135: Ajustes do Dashboard depois da revisão

- **Data:** 2026-11-16
- **Status:** Aprovada

**Complementa a [decisão 133](133.md)** (layout em blocos). Ajustes de comportamento do Dashboard na nova interface, escolhidos pelo responsável do projeto depois da revisão de design (especificação em [`levas/10B-6-dashboard.md`](../levas/10B-6-dashboard.md)):

- **Sem vendas no período, os quatro blocos de resumo continuam, zerados** (`DashboardMode.NO_SALES`). A frase com "Ver pedidos" entra no lugar do ranking. Motivo: a tela não pular ao trocar de período. Só "nada salvo" (`NOTHING_SAVED`) fica sem os blocos.
- **"Novo orçamento" é âmbar só na primeira vez** (nada salvo e período "Tudo", `DashboardUiState.newQuoteIsPrimary`). Nos demais casos o Dashboard não tem botão âmbar.
- **"Quanto cada hora rendeu" só aparece quando há hora de trabalho** configurada (`laborRatePerHour`). A hora de máquina fica só no bloco de resumo de cima.
- **Bloco de resumo sem dado mostra meia-risca apagada**, em vez de zero que parece medida.
- **Lucro negativo em vermelho** (`error`). O âmbar fica só pro lucro positivo ou zero.
- **"Orçamentos que viraram venda" some** quando nenhum orçamento foi criado no período.
