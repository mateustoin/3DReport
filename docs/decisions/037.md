# Decisão 37: Cliente embutido opcional no orçamento e status do pedido (OrderStatus)

- **Data:** 2026-09-16
- **Status:** Aprovada

Cliente vinculado ao orçamento: campo **embutido opcional** em `SavedQuote` (`Client(name, contact?)`), no mesmo espírito de `sourceLink` — não um catálogo reaproveitável como `Service`/`Filament`/`Printer`, por não haver ainda pedido de autocomplete ou histórico por cliente. Uso só interno (Histórico), nunca exportado em PDF ou copiar/colar, mesma régua do link do modelo. Status do pedido: novo enum `OrderStatus` (Orçado → Aprovado → Em impressão → Pronto → Entregue, padrão `ORCADO`), editável no Histórico (dropdown por linha), também uso só interno
