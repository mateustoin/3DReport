# Decisão 40: Filamento com várias cores (colors), cada uma com estoque (refina a 39)

- **Data:** 2026-09-16
- **Status:** Aprovada

Refinamento da decisão 39: um filamento (mesma marca/preço/densidade) passa a admitir **várias cores** (`Filament.colorName`/`colorHex`/`inStock` viram uma lista `colors: List<FilamentColor>`, cada uma com seu próprio controle de estoque), evitando cadastro duplicado quando só a cor muda. Tela de Orçamento ganha um **segundo dropdown "Cor"**, visível só quando o filamento escolhido tem mais de uma cor em estoque — a cor não afeta o cálculo (preço/densidade continuam do filamento), só fica registrada em `PrintJob.filamentColor` (uso interno, exibida no Histórico, nunca exportada). Seletor de cor personalizada: **campo de hex com prévia** (`#RRGGBB`) ao lado da paleta de cores prontas, em vez de um seletor visual completo (matiz/saturação) — mais rápido de implementar e cobre o caso de "não tem esse tom nos presets". Sem migração de dados: como nenhuma versão com o formato antigo (decisão 39) chegou a ser publicada em release, o campo antigo é substituído diretamente
