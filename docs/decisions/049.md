# Decisão 49: Preparativos de repositório público: README e site em português, CI, SEO

- **Data:** 2026-09-17
- **Status:** Aprovada

Preparativos pra tornar o repositório receptível a público antes de abrir (decisão 15): (1) descrição do repositório e tópicos do GitHub configurados (`gh repo edit`), focados em quem vende impressão 3D; (2) README/site em **só português** (público-alvo é o mercado brasileiro, mesmo idioma da documentação já existente) — sem versão em inglês por ora; (3) escopo adiantado da seção 4 do roadmap (CI, `CONTRIBUTING.md`, templates de issue/PR, badges) — `CODE_OF_CONDUCT.md` avaliado e deixado de fora por ora; (4) site institucional em `site/` (HTML/CSS estático, sem framework), publicado via `.github/workflows/pages.yml` (GitHub Actions → GitHub Pages), landing page + manual rápido em página própria, com SEO (meta tags, JSON-LD, `sitemap.xml`, `robots.txt`) voltado a termos como "orçamento impressão 3D". **Observação técnica:** a configuração de Pages (`Settings → Pages`) já foi criada via API com `build_type=workflow` — isso não publica nada sozinho (só quando o workflow rodar após um push), mas GitHub Pages de repositório privado é servido publicamente na internet mesmo assim (não existe controle de acesso por privacidade do repo fora de plano Enterprise Cloud) — outro motivo pra não fazer push do primeiro deploy antes do responsável decidir tornar o repositório público
