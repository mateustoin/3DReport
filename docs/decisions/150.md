# Decisão 150: Código de rastreio no pedido

- **Data:** 2026-11-17
- **Status:** Aprovada

**"Editar detalhes" do pedido ganha "Código de rastreio"** (`SavedQuote.trackingCode: String?`, texto livre, opcional, `QuoteDetails.trackingCode`). Reabrir o cálculo e salvar mantém o código; duplicar não o copia.

**Site de rastreio** (`OrderSettings`, Configurações > Pedidos): endereço com `{codigo}` no lugar do código. Nasce com o site oficial dos Correios, `https://rastreamento.correios.com.br/app/index.php?objetos={codigo}` (abre com o código no campo; a pessoa clica em Consultar e passa pela verificação de segurança do site). Nada gravado vale o padrão do app; apagar o campo significa sem link.

**Uso.** Pedido com código: o menu ganha "Ver rastreio" (abre o endereço, se houver) e "Copiar código de rastreio". O código entra na mensagem "Saiu pra entrega" (decisão 148). **Nunca entra no PDF nem na imagem.**

**Alternativas descartadas.**
- Consultar o rastreio dentro do app: exigiria API e internet; o link abre no navegador, por escolha da pessoa.
- Endereço fixo dos Correios: quem usa outra transportadora precisa poder trocar.

**Fica pra depois.** Frete e etiqueta pela conta do vendedor (Leva 18).
