# Decisão 42: Ícone gerado por código e atalho de instalação sempre criado

- **Data:** 2026-09-17
- **Status:** Aprovada

Ícone do app: criado programaticamente (cubo isométrico "em camadas" + bico de impressão, cores da paleta do app), sem ferramenta de imagem externa — desenhado via Java2D num script único, com os contêineres `.ico`/`.icns` montados byte a byte (formato documentado, sem precisar de `iconutil`/ImageMagick). Atalho de instalação: a ferramenta de empacotamento (jpackage/WiX, via Compose Multiplatform) **não expõe** a opção de caixinha "criar atalho?" durante a instalação (`--win-shortcut-prompt` do jpackage não tem equivalente na DSL do plugin Gradle, confirmado lendo o código-fonte do plugin) — só um `Boolean` fixo (`shortcut = true`/`false`, sempre cria ou nunca cria). Optou-se por **sempre criar** atalho na área de trabalho e no menu Iniciar no Windows (e no Linux), em vez de investir em contornar essa limitação com uma tarefa Gradle customizada chamando o jpackage diretamente
