# Decisão 46: Quatro moedas (BRL, USD, EUR, GBP) com separadores próprios, via LocalCurrency

- **Data:** 2026-09-17
- **Status:** Aprovada

Múltiplas moedas/localização: 4 moedas (BRL, USD, EUR, GBP — confirmado com o responsável do projeto), cada uma com símbolo **e** convenção própria de separador decimal/milhar (BRL/EUR usam vírgula decimal e ponto de milhar; USD/GBP o inverso) — não é só trocar o símbolo. Escolhida em Configurações → Moeda (`CurrencyRepository`, mesmo padrão do `ThemeRepository`), aplicada em tempo real. Threading: telas usam `@Composable fun Double.toMoney()`, lendo um `CompositionLocal` (`LocalCurrency`) provido uma vez no topo de `App.kt` — nenhuma tela recebe a moeda como parâmetro, só chama `.toMoney()` como já chamava `.toBrl()` antes (renomeado por clareza). PDF e copiar/colar, por rodarem fora de composição, usam uma função pura `toCurrencyText(currency = Currency.BRL)` com parâmetro default, passada explicitamente pelo `QuoteHistoryViewModel` (que ganhou `CurrencyRepository` como dependência). De passagem, a formatação ganhou separador de milhar, que não existia antes ("R$ 1234,50" virava "R$ 1.234,50"). Não traduz a UI (só a moeda) — fora do escopo do pedido do roadmap
