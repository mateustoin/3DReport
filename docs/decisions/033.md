# Decisão 33: Instaladores via GitHub Actions por tag vX.Y.Z, release em rascunho, sem assinatura

- **Data:** 2026-09-15
- **Status:** Aprovada

Distribuição dos instaladores: **GitHub Actions** (`.github/workflows/release.yml`), disparado só por **push de tag** `vX.Y.Z` — nunca automaticamente; sempre confirmar com o responsável antes de criar/empurrar a tag. Builda `.deb`/`.msi`/`.dmg` em 3 runners (um por SO, já que `packageDistributionForCurrentOS` não faz cross-compilation) e junta num **GitHub Release em rascunho** (nunca publicado automaticamente), com a descrição preenchida a partir do `CHANGELOG.md`. Sem assinatura de código por ora (custo recorrente incompatível com o modelo de doação, decisão 15) — usuário precisa ignorar o aviso do SmartScreen/Gatekeeper na primeira execução. Escopo restrito a build de release sob demanda; não reabre a decisão 17 (CI completo de build+teste a cada push segue adiado enquanto o repositório é privado)
