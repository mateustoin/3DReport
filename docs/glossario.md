# Glossário português e inglês

Os termos do app em inglês seguem esta tabela (decisão 154). Termos que não estão aqui
seguem o uso de vendedores de impressão 3D (Etsy, Reddit, Printables). Termo novo que se
repete entra aqui.

**Todo texto novo nasce nos dois idiomas.** Quem acrescenta uma chave em
`composeResources/values/` acrescenta a mesma chave em `values-en/`, com os mesmos
marcadores. O `StringResourceParityTest` trava o build se faltar chave, se os marcadores ou
os plurais diferirem ou se um texto em inglês tiver travessão. Ver
[development.md](development.md#textos-novos-nos-dois-idiomas).

## Termos principais (aprovados na decisão 154)

| Português | English |
|---|---|
| Orçamento | Quote |
| Pedido | Order |
| Catálogo | Catalog |
| Produto | Product |
| Sinal | Deposit |
| Insumos | Supplies |
| Serviços | Services |
| Canal de venda | Sales channel |
| Reserva pra falhas | Failure reserve |
| Orçado / Aprovado / Imprimindo / Pronto / Entregue / Cancelado | Quoted / Approved / Printing / Ready / Delivered / Cancelled |
| Gerado com 3DReport | Made with 3DReport |
